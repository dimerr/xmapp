# XMApp

Public privacy policy and issue tracker for XMApp, a camera client for
XM-compatible cameras and NVRs.

- [Privacy policy](https://dimerr.github.io/xmapp/privacy/)
- [Report a bug](https://github.com/dimerr/xmapp/issues/new?template=bug_report.yml)
- [Request a feature](https://github.com/dimerr/xmapp/issues/new?template=feature_request.yml)

This repository does not contain the app source code.

XMApp is not affiliated with XMEye, JF Tech, or XCloudSDK.
