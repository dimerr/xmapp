Installer mode is a safety setting for XMApp. It reveals advanced settings
that can break camera connectivity if changed incorrectly, so they are hidden
from everyday users by default.

## What it does

- Reveals installer-level settings.
- Does not change anything by itself.

## What it does not do

- It does not set P2P or status servers.
- It does not change camera credentials.
- It does not unlock paid content or App Store features.

Settings are applied only when the user edits and saves them. The app shows a
confirmation before changing server endpoints.

## Enabling it

Scan the installer QR code provided by your supplier. Only use codes from a
source you trust.
